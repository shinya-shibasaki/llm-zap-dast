# 深刻度の付け方（CVSS v4.0）

各指摘の深刻度（Critical / High / Medium / Low）は CVSS v4.0 を評価のベースとして付けます。

- 各指摘ごとに CVSS v4.0 の**ベクター文字列を選び**、対応する基本スコア（CVSS-B）を併記します。
  使ったベクター文字列とスコアを**その指摘に必ず併記**します（後から検証・再現できるように）。
- **ベクター文字列が正、数値スコアは参考値です。** CVSS v4.0 のスコアは式ではなく **MacroVector の
  ルックアップ**で決まるため、計算機を使わずに出した数値は当てになりません。ベクターとスコアが
  矛盾する場合は**ベクターを優先**し、「スコアは参考値（未検算）」と添えます。読み手が正確な値を
  必要とするなら、公式計算機にベクターを入れれば再現できます——だからベクターの方が重要です。
- スコアと深刻度バンドの対応は CVSS 標準に従います：
  - None=0.0 / Low=0.1〜3.9 / Medium=4.0〜6.9 / High=7.0〜8.9 / Critical=9.0〜10.0
- **開発/本番の差**：本番公開を前提としたスコアを主として付け、開発環境（ローカル・外部非公開）で
  下がる場合はその差を一言添えます（必要なら環境込みスコアで補足してよい）。
- CVSS は専門用語なので、レポート本文では「**深刻度バンド＋平易な説明**」を主に見せ、ベクター文字列と
  スコアは根拠として併記します（CVSS という語にも短い言い換えを添える）。
- 深刻度がスコアバンドと食い違う場合（例：影響は甚大だが CVSS-B は High 止まり）は、**バンドはスコアに
  従い**、影響の大きさは本文で補足します。

**静的診断であることの注記**：SAST は「コード上そう見える」までしか言えません。悪用可能性を実証して
いない指摘に、実証済みと同じ深刻度を付けないでください。実証できないものは「要確認」に整理します
（`report-format.md` の最終まとめ）。
